[ MODULE 4: LINUX USERS ]
- User is an account represent a person,service that interacts with the system.
- linux is mutliuser OS.
- Each user is identified by User ID(UID) & (GIDs).
- Types of user;
	Root user(UID 0 )
	  - who has complete control over the system,can install software,modify system files,manage users and controll hardware.
	Normal user(UID >= 1000)
	  - these users have limited permissions  and cannot makse system-wide changes without elevated privileges(SUDO).
	  - created for everday use
	System users(UID <1000)
	  - these users do not log in interactively and improve security by isolating services.
	  - used by system services and applications (web servers,databses).
- Linux enforces security through file ownership,permisiions (read,write,execute),and access control,ensuring users can only accesss what they are authorized to use.
[ MODULE 5: LINUX VS WINDOWS ]
- linux and windows differ mainly in licensing,security,customization and usage.
- linux allows users to view ,modify and distribute its soucre code,highly customizable and community driven{ OPEN-SOUCRED OS}.
- windows is closed-source and contolled by Microsoft,offrering a consistent but less flexible environment.
- linux is more secure and stable especially for servers,because of strong permission controls and fewer malware thearts.
- Windows is seucre but more often and commonly tageted by malware due to its large user base.
- windows excels in desktop usablitiy,gamimg and commercial software support.
- linux dominates in servers,cloud platforms, development environments.

[MODULE 1: VIRTUALIZATION ]
- It is a technology that allows to create virtual versions of computing resources such as servers,OS,storage and networks on single physical machine.
- Physcial Hardware(CPU,RAM,Disk,Network Virtualization enabled in BIOS);
	> Hypervisor{ type-1(KVM,ESXi) or type-2(Virtual box)}
	  * VM 1(Linux)
	  * VM 2(Windows)
	  * VM 3(SErver OS)
- Virtual machine is a virtual compeuter which runs its own OS and applications using shared physical hardware.
- mutliple VMs runs simultaneously.
- components of a VM;
	> each Vm as
	  * Guest OS- Linux,Windows,etc.
	  * vCPU- virtual processor
	  * vRAm- Virtual memory
	  * Virtual Disk- File-based storage(VDI<VMDK)
	  * virtual Network Adapter
- workflow;
	> Physical hardware
	> Hypervisor Installed
	> Virtual machine created
	> Guest OS Installed 
	> VM Runs
- Virtualizaion types;
	> Server Virtualization{cloud and data centers(AWS,AZURE,GCP)}
	> Operating System Virtualization{DevOps pipelines,CI/CD(docker,kubernetes,podman)}
	> Desktop Virtualization(Enterprise,call centers,secure environmentes)
	> Storage Virtualization(LVM in linux,SAN/NAS Systems,google drive)
	> Netwrok Virtualization(VLANs,virtual switches in hypervisors,Software Defined Netwroking)
	> Application Virtualization(microsoft app-v)
- Virtual Box 
	> It is a open-source softtware that allows to run multiple OS on a single physcial computer at a same time.
	> It installs  on host)S(windows,Linux,MacOS) and runs guest OSes
		* Linux(Ununtu,CentOS,AL2023,Kali,etc.)
		* windows
		* BSD and others
	> Each guest OS behaves like a real computer with its own CPU,RRAM Hard Disk,Network.
	> compotents of VirtualBox
	  * Host OS
	  * Guest Os
	  *  VM

[ MODULE 3: SYSTEM ACCESS & FILE SYSTEM]
-  File System Structure and its Description
	> / ~ Root directory
	> /bin ~ Essential user commands
	> /boot ~ bootloader files( kernel,initrd,grub configs)
	> /dev ~ device files(disks,usb,terminal,etc)
	> /etc ~ system configuration files and scripts
	> /home ~ user home dir
	> /lib ~ shared libraries needed by /bin and /sbin
	> /media ~ mount points for removable media(USB,CD)
	> /mnt ~ temporar mount points for filesystems
	> /opt ~ optinonal software packages
	> /proc ~ virtual files represnting kernel amd process info
	> /root ~ home dir for root
	> /run ~ runtime date(process IDs,sockets,etc) 
	> /sbin ~ essential system adminstration commands
	> /srv ~ data for services(web,ftp)
	> /sys ~ kernel and device management interace
	> /tmp ~ temporary file(cleared or reboot)
	> /usr ~ user programs,lib and doc
	> /var ~ variable data(logs,spool files caches)
